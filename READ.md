# Vacancy Console App

## Описание

Это консольное приложение для поиска, сохранения и управления вакансиями с помощью API hh.ru.
Вы можете искать вакансии по ключевым словам, сохранять их в файл, просматривать топ вакансий по зарплате, фильтровать по ключевым словам и удалять вакансии.

## Основные возможности

- **Поиск вакансий** по ключевому слову через hh.ru API
- **Сохранение найденных вакансий** в файлы формата `json`, `csv` или `txt`
- **Просмотр топ N вакансий** по зарплате из сохранённых файлов
- **Фильтрация вакансий** по ключевому слову в описании или названии
- **Удаление вакансий** по URL из выбранного файла

## Быстрый старт

1. Установите зависимости:
    ```
    pip install -r requirements.txt
    ```

2. Запустите приложение:
    ```
    python main.py
    ```

3. Следуйте меню для поиска и управления вакансиями.

## Структура проекта

- `src/api_handler.py` — классы для работы с hh.ru API
- `src/files/` — классы для работы с файлами (json, csv, txt)
- `src/vacancy.py` — модель вакансии
- `src/utils.py` — консольный интерфейс пользователя
- `main.py` — точка входа приложения
